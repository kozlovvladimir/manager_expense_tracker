Budget Sales Tracking
=====================

Budget Sales Tracking is a module for tracking workdays, mileage, and financial transactions of budget sales managers in Odoo 18. It integrates with Odoo's HR, accounting, fleet, and sales modules, providing a comprehensive solution for managing sales budgets, including workday tracking, fuel prices, financial records, and daily reports.

Key Features:
-------------------

- **Budget Sales Manager Management**: Add, edit, and delete manager profiles.
- **Workday Tracking**
- **Fuel Price Management**
- **Financial Records**
- **Daily Reports**
- **User Interface**
- **Security**

How to Install the Module?
----------------------

1. Copy the module to the `custom_addons` directory.
2. Make sure the path to `custom_addons` is listed in `odoo.conf`.
3. Restart Odoo and install the module.

How to Use?
-----------------

1. **Budget Sales Managers**
2. **Managers' Workdays**
3. **Fuel Prices**
4. **Financial Records**
5. **Daily Reports**
